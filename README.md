# EV Charging Station Market Entry Analysis

## Project Overview
Analyzed EV charging infrastructure data to explore market coverage, ownership patterns, and potential market-entry opportunities.

## Tools Used
- Python (Pandas) — Data extraction and cleaning
- MySQL — Data analysis using SQL
- Power BI — Interactive dashboard development

## Dataset
- **3,039 records**
- **12 columns**
- **8 states/UTs**
- Government and private charging infrastructure

## Key Insights
- Government-owned records account for approximately 66.7% of the dataset.
- Delhi has the highest number of station records (883).
- Andhra Pradesh has the highest number of connectors (1,062).
- West Delhi has the highest district-level record count (440).

## Recommendations
- Explore opportunities in lower-coverage districts.
- Encourage private-sector participation.
- Assess connector availability across states.
- Explore partnerships with established charging operators.

## Project Files
- `EV_Charging_Cleaned.csv` — Cleaned dataset
- Power BI dashboard (`.pbix`)
- Project report (`.pdf`)

## Data Limitation
This analysis uses a sample of 3,039 records across 8 states/UTs. Results may not represent India's complete EV charging infrastructure, and each record is not necessarily a unique physical charging station.
